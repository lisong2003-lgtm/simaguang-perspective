# 量化推演模板

## 问题

一句话写明：要决定什么，约束是什么，风险是什么。

## 关键假设

| 变量 | 保守值 | 基准值 | 乐观值 | 依据 |
|---|---|---|---|---|
| 收入/收益 |  |  |  |  |
| 成本/损失 |  |  |  |  |
| 时间 |  |  |  |  |
| 概率 |  |  |  |  |
| 外部条件 |  |  |  |  |

## 三档情景

- 保守：假设最差但不极端，给出结果。
- 基准：假设最可能，给出结果。
- 乐观：假设有利条件，给出结果。

## 决策树

1. 列出决策点。
2. 列出每个选项的可能结果。
3. 给每个结果标概率。
4. 计算期望值，但不只看期望值，还要看最坏情况。

## 敏感性分析

找出影响最大的 2-3 个变量，逐一变化 10%、20%、50%，记录结果如何变化。

## 最坏情况

- 最大损失是多少？
- 能否承受？
- 需要什么保险、缓冲、退出条件？

## 复查点

- 第 1 周核验什么？
- 第 2 周核验什么？
- 第 1 个月核验什么？
- 什么信号出现就要改路径？

## 输出纪律

- 数据缺失标“待核验”。
- 概率必须给推理链。
- 模型是辅助，不替代真实决策。
