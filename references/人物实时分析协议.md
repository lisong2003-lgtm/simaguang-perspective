# 司马光综合思维 · 人物实时分析协议（照片 / 摄像头 / 视频帧）

把 ds-vision-skill 的视觉采集能力接入 40 节点神经网络，用于分析“一个人或一群人”的公开可观察信号。所有结论按证据分级，禁止脑补。

## 一、能力边界

- 静态照片：用户给路径，或名人图片池自动选取。
- 摄像头：`ds-vision-skill/scripts/camera-capture.sh -o <输出.jpg> -j` 拍照。
- 实时观察：当前链路是“定时抽帧 + 逐帧分析”，不是逐秒视频理解；建议 5-30 秒抽一帧。
- 视频文件：本机未装 ffmpeg 时，要求用户提供截图或逐帧图片；有 ffmpeg 时再支持自动抽帧。
- 图中文字：先 `baidu-ocr.sh`，失败用 `tesseract-ocr.sh`；复杂视觉推理用 `vlm-vision.sh -c glm-thinking`。
- 无视觉通道时：明确标注“视觉语义待配置”，不脑补画面内容。

## 二、运行链路（L0-L4）

0. 采集（N36）：照片/摄像头帧/文字 OCR 统一成可核验证据。
1. 质检（L1，N24/N20/N17/N9/N39）：把画面、文字、陈述分开；先标“待核验证据”；拒绝把单帧表情当结论。
2. 分析（L2，N37/N40/N15/N2/N23/N10）：三区表情、身体语言、冰鉴形格、动机、群体情绪。
3. 策略（L3，N38/N3/N7/N25/N26/N27/N31/N32）：谎言线索、意图、博弈、权力风险、心理韧性。
4. 仲裁（L4，N28/N1 + 案例库）：历史类比、多源验证。
5. 辩证：反方先批判，输出相反视角并用历史案例佐证。
6. 输出与复盘：按人物速写卡输出，并自评哪个模块被高估或忽略。

## 三、观察清单

- 基线：记录中性状态下的表情、姿态、语速、手势频率，作为比较基准。
- 表情：三区蓝图（眉额/眼鼻/嘴下巴）、微表情、混合表情、真假笑、左右不对称。
- 身体：手脚方向、安慰行为、开放/封闭、主导/服从、距离变化。
- 言语（能听到或看到文字时）：停顿、口误、声调、绝对词、细节密度（SVA/真实监控）。
- 关系：对话中的权力动态、服从信号、情绪传染、话题切换点。
- 触发点：记录“哪个话题出现变化”，不记录“他一定在说谎”。

## 五、人物速写卡（输出模板）

【观察对象 / 时间 / 场景】
【视觉证据】（帧号/来源/置信度）
【表情与身体语言观察】（N37/N40）
【心理画像】（N15/N2）
【压力与掩饰线索】（N38/N39）
【意图与博弈】（N26/N27/N25）
【历史类比】（N28）
【综合建议】（可执行动作、优先级、风险）
【相反辩证视角】（用历史案例佐证）
【置信度与边界声明】

置信度规则：单一信号 = 低；跨层同向 = 中；跨模态 + 历史类比 + 独立证据 = 高。数据缺失一律标“待验证”。

## 六·五、人物图片四书联析模式（“司马光分析”默认触发）

当用户上传人物图片并说“司马光分析”“用司马光看这个人”“分析这张人像”时，按以下固定链路执行：

### 触发与采集

1. 先用 ds-vision-skill 处理图片：复杂视觉用 `vlm-vision.sh -c glm-thinking`，图中文字用 OCR，无视觉通道时标“视觉语义待配置”。
2. 只分析图片中可观察到的信息，不脑补画面外内容。

### 四书并行

按顺序并行激活四个传统识人模块，每个模块只输出“可观察项 + 文化启发结论”：

- 冰鉴（N2）：神骨、气色、刚柔、情态、声音、器识。
- 柳庄神相（N45）：神气心田、骨格形局、三停五岳、五官六府、声音、气色、流年框架。
- 神相全编（N44）：十观、五行形局、五官六府、三停、五岳四渎、神气声音。
- 人物志（N43）：九征、五常、八观、五视、七缪、英雄、十二材。

### 辅助模块

- 读脸术（N37）：三区表情、微表情、真假笑、左右不对称。
- 身体语言（N40）：姿态、手势、方向、安慰行为、场景化。
- 厚黑防御（N42）：捧杀、恩惠、试探、表演等操纵信号。
- 心理学与生活（N41）：神态稳定度、压力线索、人格与情境解释。

### 综合辩证

1. L1 质检：把“图片里看到什么”和“我推断什么”分开，单帧结论一律低置信。
2. L2 人性：把四书观察合并成心理画像，标矛盾点。
3. L3 策略：结合姿势、表情、关系线索推演意图与博弈，只给概率。
4. L4 历史：从《资治通鉴》《读通鉴论》找相似人物或情境，标同构边界。
5. 强制辩证：输出与主流判断相反的视角并用历史案例佐证。
6. 输出人物速写卡，末尾附置信度与边界声明。

【冰鉴】
【柳庄神相】

【辅助模块】（读脸/身体语言/厚黑/心理）
【综合辩证】（L1-L4）
【历史类比】
【相反辩证视角】
【置信度与边界】

### 硬规则

- 相法模块一律标“文化启发/待验证”，不预测命运，不用于招聘、司法、健康结论。
- 单张静态图只能给情绪、气质、协调性的低置信线索；判断“是否说谎、是否可信”必须补多帧、行为记录或言语证据。
- 四书结论冲突时，以可观察行为证据和独立事实优先，不以相术断语压过证据。
- 新发现的可复用规则先到 `进化判断尺.md` 查重，再决定是否进化。

## 七、边界与伦理

- 分析前明确告知并取得同意；摄像头数据只用于当前会话，不落盘长期存储。
- 不分析非公开人物的私人生活；不做心理疾病诊断、司法结论、人事/信用结论。
- 图片只能作为证据的一部分，不能替代行为记录和可验证事实。
- 名人公开图片按 `名人分析协议.md` 处理；新规则先到 `进化判断尺.md` 查重。
- 没有视觉通道、看不清楚或证据不足时，明确说“待验证”，不臆造动机。
