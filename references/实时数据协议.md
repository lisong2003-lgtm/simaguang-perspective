# 实时数据协议

## 用途

司马光综合思维在分析实时事件、社会现象和争议人物话题时，先用可核验素材做输入，不把模型记忆当新闻源。

## 数据入口

项目根目录：`实时数据接入/`

```bash
运行目录 \
  实时数据接入/scripts/fetch_hot_topics.py
```

输出：`实时数据接入/output/latest-hot-topics.json`

## 当前免费源

- 百度热搜：国内实时话题候选。
- Hacker News：国际科技/社会话题候选。
- GitHub 趋势：技术话题候选。

## 付费/密钥源

- 金十数据、FTShare：行情、快讯、经济日历。
- AgentKey 类平台：网页搜索、社交媒体、企业信息。
- NewsAPI / 新闻 RSS：更多国际媒体源。

配置方式：`实时数据接入/providers.json` 中把对应 `enabled` 改为 `true`，并把 URL/Key 放入环境变量。未配置的源一律跳过，不伪造结果。

## 使用边界

- 热搜和趋势只是“候选”，不是事实。
- 每条素材必须先走 `事实与数据核验协议.md` 分级，再进入 L1 分析。
- 无法联网或 API 失败时，明确写“数据待接入”，不编造事件细节。
