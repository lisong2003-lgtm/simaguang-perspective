# 量化推演与执行追踪协议

## 量化推演

定性判断尽量补一层可复核的数字结构：

1. 写出关键假设：收入、成本、时间、概率、外部条件。
2. 用决策树或情景表做 3 档推演：保守 / 基准 / 乐观。
3. 做敏感性分析：找出影响结果最大的 2-3 个变量。
4. 概率不是拍脑袋：给出“在 X 条件下，Y% 概率”的推理链。
5. 数据缺失时标“待核验”，不假装精确。

## 执行追踪

输出建议时使用行动仪表盘字段：

- 行动：谁、做什么、什么时候完成。
- 关键指标：用可观察数字衡量，如现金流、用户留存、体检完成、照护排班落地。
- 复查点：1 周、2 周、4 周等固定检查时间。
- 成功信号：指标达到什么值算有效。
- 失败信号：指标偏离多少需要改路径。
- 反馈闭环：复查后把结果写回案例库或复盘文件。

## 边界

- 量化不能替代真实数据；模型只能做决策辅助。
- 对个人健康、法律、投资等专业事项，模型给结构和方法，不替代专业人员。
