# 学习循环协议（2026-08-13）

## 定位

把“自我学习”从概念变成主技能每次分析后自动执行的闭环：

主技能（人格+流程）→ 技能包（蒸馏模块）→ 原始书籍文档（知识库）

每一层都保留来源，学习结果回写学习日志，再反哺补给、蒸馏和调用。

## 六步循环

### 1. 反思：每次分析后自我评分

每次分析结束后，内部记录到 `运行目录/学习记录/学习日志.md`，不把完整自我评估作为用户输出主体。

记录格式：

```markdown
## YYYY-MM-DD 分析：标题
- 使用的书籍技能：[书籍1、书籍2]
- 置信度：高 / 中 / 低
- 不确定部分：...
- 知识缺口：是 / 否；具体缺什么
- 用户追问/纠正：无 / 具体记录
- 建议补充：无 / 建议方向
```

不确定结论必须同时标注“可查技能原文”中的来源书，便于后续定位。

### 2. 识别：复盘学习日志

触发方式：

- 用户说“复盘学习日志”。
- 每周日自动化运行。
- 学习日志新增满 10 条后主动运行。

执行：

```bash
python3 skills/simaguang-perspective/scripts/review_learning_log.py \
  --log 运行目录/学习记录/学习日志.md \
  --out 运行目录/学习记录/学习复盘-<日期>.md
```

识别内容：

- 哪类问题最常出现“不确定”。
- 哪类问题最常被用户追问或纠正。
- 哪些书/模块被调用最多，哪些最少。
- 哪些建议补充方向重复出现。
- 哪些技能路由反馈或用户纠正最常出现。

路由反馈候选：从运行目录学习日志提取，从 `运行目录/学习记录/学习日志.md` 提取尚未进入反馈日志的用户纠正，输出到 `运行目录/学习记录/技能路由反馈候选-<日期>.md`。

### 3. 规划：提出补充计划

复盘后生成 `运行目录/学习记录/补给申请/补充计划-<日期>.md`，按 P0/P1/P2 排序。

每项必须遵守 `主动学习补给协议.md` 的补给论证：

- 为什么现在是补充时机。
- 补到什么深度。
- 不及时补会有什么具体后果。

### 4. 执行：定向蒸馏

用户确认后，按内部 `蒸馏能力协议.md` 执行：

- 先对照 `主动学习补给单-<日期>.md`。
- 命中短板则标记“定向补给”。
- 产出技能包、提取文本，并并入主技能、方法网络和测试。

### 5. 验证：学习前后对比

补充完成后，在后续同类分析中对比：

- 不确定程度是否降低。
- 用户追问或纠正频率是否减少。
- 是否有新的不确定点。

对比结果写入 `运行目录/学习记录/学习日志.md` 和 `运行目录/学习记录/学习复盘-<日期>.md`。

### 6. 沉淀：生成结构化记忆卡与公开版本

每次分析结束后，把可复用内容沉淀成记忆卡，再根据是否需要公开生成脱敏版本。

执行顺序：

1. 先写入结构化记忆卡，字段见下一节。
2. 复杂案例另存到 `运行目录/学习记录/知识卡/<日期>-<标题>.md`。
3. 需要公开时，先生成脱敏副本，再进入公共技能包。
4. 公开前运行核验工具，确认没有私人信息、内部路径和未授权版权文本。

沉淀原则：案例越多，越像“你”，也就是司马光综合思维；不是像某个具体用户。公共版本得到的是“方法论副本”，私人记忆和版权原文不能进入公共版本。

## 结构化记忆卡

为了让记忆可复查、可过期，每次分析除写入学习日志外，还应沉淀成一条结构化记忆卡。复杂分析单独保存到 `运行目录/学习记录/知识卡/<日期>-<标题>.md`，简单分析合并到 `运行目录/学习记录/学习日志.md`。

记忆卡字段：

```markdown
## 记忆卡：<主题>
- 核心判断：一句话
- 关键信号：后续出现什么事实会支持或推翻
- 来源书：实际调用的书
- 置信度：高 / 中 / 低
- 验证状态：未验证 / 已核对原文 / 已被新信息修正
- 复查日期：下次复查时间
- 用户纠正：无 / 具体记录
```

沉淀规则：

- 不把“这本书说过”当作结论，只记录“该结论依赖哪本书的哪条判断尺”。
- 有版权限制的书籍只记录短引用和来源元数据，不复制大段原文。
- 新信息与旧记忆卡冲突时，新增修正记录，不直接抹掉旧判断。
- 每周复盘时，先检查到期记忆卡，再检查不确定项。

## 公共版本与脱敏

案例越多，记忆卡越像“你”，也就是司马光综合思维；但公共版本不能直接复制私有学习记录。

公共版本只保留：

- 主 SKILL、判断尺和协议。
- 脱敏后的案例模板，不包含真实姓名、单位、地点、聊天记录和私人信息。
- 测试提示词和输出样例。
- 公有领域或已获授权的原文短引用与来源元数据。

公开前必须移除：

- 原始学习日志和记忆卡中的个人信息。
- 用户真实案例、对话原文和内部文件路径。
- 未授权版权书的全文或大段文本。
- 任何可能反推出具体个人的细节。

公开版本像“你”（司马光综合思维），不像某个具体用户；这种“像”是方法论层面的像，不是私人记忆层面的复制。

- 与每周热点自动化共用 `运行目录/学习记录/热点追踪表.md`、`运行目录/学习记录/补给申请/` 和 `references/自我学习日志.md`。
- 每新增一本书或技能，仍需同步 `融汇贯通协议.md` 要求的全部文件。
