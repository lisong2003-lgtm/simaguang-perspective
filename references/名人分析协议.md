# 司马光综合思维 · 名人图片分析协议

## 输入

1. 运行 `可选公开人物图片采集`，自动从 Wikimedia Commons 公共图片池选取下一位名人。
2. 读取 `运行目录/名人公开图片/current.json`，获得 `name`、`image_path`、`source_url`、`commons_file`、`summary`。

## 分析步骤

1. 先用 ds-vision-skill 处理图片：有视觉通道时调用 `vlm-vision.sh`；至少用 `tesseract-ocr.sh` 提取图中可见文字。
2. 用名人公开履历和 `summary` 补充背景，不依赖不可验证的私人信息。
3. 激活节点：N36 视觉输入、N2 用人识人、N3 形势时机、N10 群体舆论、N15 人性洞察、N28 史鉴。
4. 输出“名人分析卡”：公开形象观察、关键公开记录、优势与风险、可借鉴规则、置信度、证据来源。

## 边界

- 只分析公开人物形象、公开行为和公开言论，不分析私人生活。
- 不做健康、法律、财务等专业结论，不构成诽谤或人格攻击。
- 图片来源保留 Wikimedia Commons 链接；分析结果不得声称代表当事人本人立场。
- 没有可验证证据时标“待验证”，不脑补当事人动机。
