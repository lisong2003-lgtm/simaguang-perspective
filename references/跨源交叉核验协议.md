# 跨源交叉核验协议

> 目标：让司马光综合思维的“事件分析”不依赖单一来源、不把未经核验的素材当作事实，并在落盘层面守住脱敏红线。

## 1. URL 去重与规范化

- 同一内容只保留一个规范 URL：去掉跟踪参数（utm_*/source/sid）、统一协议与默认端口、保留原始权威域名。
- 转载链接与原创链接并存时，优先保留原创；转载只登记为「转载来源」。
- 已去重、已登记的 URL 再次出现时返回原编号，不重复入库。

## 2. 立场标签

每条素材入库时打一个立场标签：

- `NEUTRAL`：行业报告、公开数据、制度文件，立场中性。
- `AUTHORED`：作者观点、评论、深度访谈，带明显写作立场。
- `VOICE`：以当事人/社区/用户视角讲述的第一手经验（不视为全面事实）。
- `OFFICIAL_CALL`：官方活动公告或栏目转载，陈述性内容可作背景，不作独立证据。
- `PROMO`：推广/营销类内容，仅作线索，不进入决策链。

## 3. 交叉验证规则

- A 级：同一结论至少两个独立来源（不同机构/不同作者）表述一致，且可访问原文。
- B 级：单一权威一手源，要素提取完成但未逐字复核。
- C 级：转载/聚合来源，只有背景价值。
- 交叉验证通过前，不在判断结论里写「事实」字样，只写「该来源称……」，并给出待验证项。
- 与常识或既有证据冲突的素材，注明「需复核」，不自动采信。

## 4. 涉政敏感落盘规则（硬红线）

- 不使用企业内部数据、图纸、项目名、客户名、涉密文件。
- 不使用涉政敏感人物/事件/机构名作为测试词或素材卡；历史人物仅限公开学术史料中公认定论。
- 所有素材按上述规则扫描一次，命中即整条删除，不保留草稿。
- 不落盘隐私：姓名、住址、证件号、手机号、银行账号、工作单位内部信息一律不进入素材库。
- 平台专用展示层差异只存在于发布包，不写回本机原版。
- 发布包不得包含本机路径、用户名、机器名、邮箱、密钥。

## 5. 过期与复核

- 时效性素材（行业报告、访谈、报道）超过 120 天标记「需复核时效」。
- 缓存表按“素材编号 + 首见日期 + 立场标签 + 证据等级 + 状态”维护，复核为最新一版时更新状态，不无限堆积旧副本。
