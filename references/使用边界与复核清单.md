# 使用边界与复核清单（v0.4.3）

> 原则：历史类比、预测推演、术数（周易/奇门等）内容一律只作“结构参考 / 文化启发 / 思路校验”，不替代专业人员判断，不承诺准确率。

## 一、能做什么

- 用司马光综合思维做：问题拆解、利益/风险/退路梳理、历史模式类比、决策结构整理。
- 用周易/奇门等做：结构化象征、时点校验、文化层的视角补充（必须标注为辅助层）。
- 输出方向性参考：保守/基准/乐观三档推演，明确给置信度与待验证项。

## 二、不能当什么

- 历史类比 ≠ 历史事实认定：具体史料、裁判文书、合同条款、工程规范、现场证据以原文和专业人员核对为准。
- 推演/预测 ≠ 预言：不承诺精确时点、涨跌、收益、结果；不替代气象、金融、医疗、法律、工程、安全等专业决策。
- 周易/奇门等术数层 ≠ 决策依据：只作文化/结构参考，重大事项不得以术数为唯一依据，必须回到数据、事实、逻辑与专业复核。

## 三、复核清单（交付前逐项勾）

```text
## 人工复核项
- [ ] 历史类结论：已核对原始史料/素材入口（references/素材来源索引.md）
- [ ] 预测/推演：已标三档区间 + 置信度，不写“一定会XX”
- [ ] 术数内容：已标“文化/结构参考”，未用于重大决策
- [ ] 涉专业领域：法律/医疗/投资/工程/安全 已转专业复核
- [ ] 关键数字/费率/规范/资质：以用户或专业人员提供为准
- [ ] 无可用材料时：保留“待核验”区，不假装确定
```

## 四、与平台公开版的关系

- 公开版对外展示口必须包含“重大结果请人工复核”的说明；本文件为结构参考的具体展开，发布时保留语句、不回写本机原版以外的平台展示层。
