# 高生产力场景模板（2026-08-14）

由公开案例训练沉淀。使用前先填真实受众、目标、材料、约束和截止时间；所有数据未经验证时标“待替换”。

所有场景通用：已学的写作、表达、结构、逻辑和视觉手法在创作全程主动参与；全部已并入书籍既是灵感来源也是知识底座，可借用案例、模型、历史、专业细节和表达方式，不复制原文。

质量规则：交付前使用 `references/高生产力输出自检清单.md` 和 `scripts/run_high_productivity_checks.py`；事实核验见 `references/事实与数据核验协议.md`；专业复核见 `references/专业边界与复核清单.md`；真实反馈归档见 `references/高生产力反馈闭环协议.md`。

## 1. 产品路演 PPT 黄金 12 页

1. 封面：3 秒价值主张，一行进展，一行本轮诉求。
2. 痛点：一个具体场景或用户原话，不堆大市场数字。
3. 解决方案：一句话说清做什么，再给 2-3 个支撑点。
4. 产品：展示原型、演示图或对比图，不堆技术参数。
5. 商业模式：谁付钱、付多少、多久付一次。
6. 市场：TAM → SAM → SOM，用已有数据证明需求。
7. 运营数据：用户、留存、收入或验证结果，图表带结论。
8. 团队：为什么这个组合能做成，不是简历。
9. 财务：增长曲线、成本结构、毛利、现金流。
10. 融资用途：每笔钱去向、周期、里程碑。
11. 愿景：一个具体、可信的未来画面。
12. 封底：明确行动入口和联系方式。

每页规则：一页一结论，正文不超过 5 行；图表旁写结论；详细参数放备用隐藏页。

## 2. 项目策划书

1. 项目定位与一句话价值
2. 问题与机会
3. 主方案与备选路径
4. 关键变量与敏感性
5. 里程碑、资源与预算
6. 风险与应对
7. 复查指标与失效条件
8. 可推广性与后续路径

每条预算对应一个可交付结果；决策者砍掉一半资源时，仍能指出最小可行核心。

## 3. 招标应标

1. 先拆评分标准：实质性要求、重要参数、一般参数、方案质量。
2. 逐条响应；漏报视同负偏离。
3. 要求证明材料的条款必须附真实材料。
4. 方案按项目特点写：质量、进度、人员、资源、风险。
5. 加评分权重排序，让评委 10 分钟内能找到答案。

废标风险先清零，再争方案分；资质、业绩和承诺必须可核验。

## 4. 论文答辩

1. 课题背景与意义
2. 研究方法与核心内容
3. 数据与分析结果
4. 创新点
5. 局限性与未来工作
6. 结论

提前列评审最可能质疑的 5 个问题，每题准备证据和解释；PPT 只放路线图、核心结果和局限三页关键页。

## 5. 辩词

1. 一句话立场
2. 核心词定义
3. 判准
4. 2-4 个彼此独立的论点
5. 证据与案例
6. 最强反方与回应
7. 价值收尾

先守住定义和判准，再打事实；不攻击人格，不用稻草人，不编造数据。

## 6. 小说提纲

1. 一句话高概念：一句话说清“谁在什么世界里，为了什么，付出什么代价”。
2. 读者承诺：读完后得到什么：爽感、智识、共情、震撼，还是综合体验。
3. 世界观与规则：物理规则、社会规则、代价规则，规则是否前后一致。
4. 人物弧光：欲望、恐惧、缺陷、谎言、转变。
5. 主线冲突：目标、阻力、反方、不可逆转折。
6. 分卷/章节提纲：事件、人物变化、钩子。
7. 关键转折：中点、最低谷、真相、终局。
8. 叙事方式：视角、语气、时间线、章节节奏。

## 7. 剧本/剧集提纲

1. 一句话高概念与类型调性。
2. 受众、平台和篇幅约束。
3. 人物表：立场、关系、秘密、变化。
4. 世界观与场景规则。
5. 分幕/分集提纲：目标、冲突、转折、余波。
6. 对白与节奏：每场戏推进什么，删掉哪场会损失。
7. 场景清单：内景/外景、时间、人物、任务、结尾悬念。

## 8. 小说正文单章

1. 本章任务：推动什么、改变什么、埋下什么。
2. 视角与语气：固定视角，不随意跳头。
3. 开头钩子：用动作、异常、威胁或选择开场。
4. 正文：让事件由人物欲望和恐惧推动，不让角色被动服从情节。
5. 本章结尾：留下一个未解决的张力或新的问题。
6. 写后检查：视角一致、动机可解释、专业知识准确或标虚构。

## 9. 剧本场景正文

1. 场景信息：内景/外景、时间、人物。
2. 场景任务：这场戏要达成什么。
3. 动作与视觉：用可见行动表达情绪，不靠旁白解释。
4. 对白：每句台词都推动选择、冲突或信息变化。
5. 结尾悬念：让观众在下一场戏前产生期待。

## 10. 非虚构写作与编辑审查

1. 非虚构边界：事实、叙事判断、推断、待核验分开。
2. 选题价值：社会性、时代性、世界性、文化价值、情感共鸣。
3. 主题先行：每条素材是否服务主题，删除无关且无损害的材料。
4. 采访与素材：现场观察、核心人物、周边采访、资料与专家、确认事实。
5. 叙事四要素：直接引语、间接引语、概述、描写的组合比例。
6. 人物故事：欲望、冲突、应对动作、性格本质、时代连接。
7. 结构选择：时间线式、模块式、剥洋葱式，开头结尾承担各自任务。
8. 语言清理：去掉陈词、套话、流行语、可疑形容词，统一语气。
9. 修改工艺：朗读、打印、删冗余、调整顺序和重点。
10. 编辑终审：事实、逻辑、文笔、合规、可读性、平台调性。
11. 写作工艺检查：名词动词骨架、主动语态、副词克制、段落节奏、辞格合适、文章病院、收束方式。

## 11. 广告文案

1. 目标读者和决策路径。
2. 标题四大功能：吸引、筛选、传达、引导。
3. 卖点转功效：用户得到什么。
4. 销售五步骤：注意、需求、方案、证据、行动。
5. 信任与风险消除。
6. 测试指标和复查点。

## 12. 商务报告/提案

1. 结论先行。
2. 金字塔结构：结论、理由、证据。
3. MECE 分组。
4. SCQOR 故事线。
5. 替代方案和风险。
6. 行动与复查点。

## 13. 电影剧本/剧集大纲

1. 一句话前提。
2. 类型与观众预期。
3. 救猫咪瞬间。
4. 三幕或节拍表。
5. 人物需求与转变。
6. 激励事件、危机、高潮、结局。

## 14. 深度报道

1. 选题价值与角度。
2. 采访和信源清单。
3. 叙事结构。
4. 导语、细节、引语、数据、结尾。
5. 事实核验与编辑终审。

## 15. 书籍修订与风格润色

1. 先定读者、目标和出版/发布渠道。
2. 宏观检查结构、主题、人物、逻辑和节奏。
3. 微观检查句子、用词、标点、重复和语感。
4. 平台合规和来源标注放最后。

## 16. AI 视频/短剧提示词

1. 一句话高概念与观众承诺。
2. 剧本结构：人物、冲突、三幕或短剧节奏。
3. 分镜表格：镜号、景别、运镜、时长、画面、台词、音效。
4. 按工具生成提示词：
   - MiniMax H3：动态内容 + 参考素材职责 + 镜头指令。
   - Seedance 2.5：主体 + 动作 + 摄像机 + 灯光 + 风格 + 音频。
5. 角色一致性：Seed、参考图、角色档案或 LoRA。
6. 平台合规：AI 辅助创作标注、版权、肖像、审核规则。
7. 生成后逐帧审查，按数据反馈迭代。

## 17. 书籍修订与编辑终审

1. 初稿与修订状态分离。
2. 宏观修订：情节、人物、场景、视角、结构。
3. 微观修订：对白、句法、标点、删减。
4. 自我编辑清单：旧信息新信息、主谓邻近、名词化、元话语。
5. 时间距离与第三方反馈。
6. 风格检查：清晰、直接、古典风格、声音一致。

## 18. 小说/剧本融合创作总入口

1. 先用司马光综合思维定高概念、人物、冲突、代价和结局方向。
2. 用全部已并入书籍校准历史、人性、制度、心理、社会和专业细节。
3. 用影视摄影与短片创作簇做场面调度、景别、机位、运镜、光线、剪辑和声音设计。
4. 用 AI影视工具与提示词协议生成 AI 视频/短剧提示词、分镜表和角色一致性约束。
5. 创作时主动调用写作工艺、修辞、节奏、视角、对白和收束手法完成初稿，再用修改风格和平台规范协议完成修订与合规检查。
6. 完整规则见 `references/小说剧本融合创作协议.md`。
7. 书籍只作灵感，不复制原文、人物、情节或结局；结局先给初始方案，发布或试读后按读者反馈、故事逻辑和作者判断决定是否调整。
8. 可调用 `运行目录/创作灵感素材/四大名著/` 作为人物原型、章回结构、叙事节奏和历史情境灵感，不复制原文。
9. 科幻创作可调用 `运行目录/创作灵感素材/三体/` 作为世界观、硬核设定、文明冲突和叙事尺度灵感，不复制原文。
