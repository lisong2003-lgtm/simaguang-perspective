# 危机转介清单

## 说明

本清单只列类别和需要补充的字段，不凭记忆编造本地电话和机构。具体号码和地址必须由用户确认或由官方来源核验。

## 转介类别

| 类别 | 是否紧急 | 可联系对象 | 本地号码/地址 | 备注 |
|---|---|---|---|---|
| 生命危险/正在发生暴力 | 是 | 报警/急救 | 待补充 | 优先 110/120 |
| 自杀危机 | 是 | 专业危机干预 | 待补充 | 必须转专业 |
| 心理/精神危机 | 否 | 心理咨询/精神科 | 待补充 | 不诊断 |
| 家庭暴力/性侵 | 是/否 | 警方/妇联/法律援助/庇护机构 | 待补充 | 保护安全 |
| 法律权益 | 否 | 律师/法律援助中心 | 待补充 | 给框架不替代律师 |
| 医疗紧急 | 是 | 医院/急救 | 待补充 | 不替代医生 |
| 失踪/虐待 | 是 | 警方/专业机构 | 待补充 | 尽快转介 |
| 其他危机 | 视情况 | 专业机构 | 待补充 | 诚实承认边界 |

## 使用规则

- 出现紧急、暴力、自杀、伤害风险时，建议立即联系当地警方、急救和专业机构。
- AI 只能陪伴和转介，不能替代专业人员。
- 用户补充的本地资源必须先核验再使用。

## 待补充

- 本地心理危机热线
- 本地精神科/心理医院
- 本地法律援助中心
- 本地妇联/反家暴机构
- 本地儿童保护/社工机构
- 本地报警/急救通用号码
