# 七项能力增强执行方案（2026-08-12）

## 1. 实时数据与事实核验

已有：`实时数据接入/scripts/fetch_hot_topics.py`、`references/事实与数据核验协议.md`。

本次落地：
- 热点和新闻只作候选，不当作事实。
- 引用实时信息必须带来源、证据级别和检索时间。
- 无法核验的一律标“待核实”。

需要用户：
- 提供稳定数据源或 API Key，如新闻、政策、金融行情。
- 确认允许访问哪些网站和服务。

## 2. 量化推演

已有：`references/量化推演与执行追踪协议.md`。

本次落地：
- 新增 `references/量化推演模板.md`，用于财务、公司、家庭和个人决策。
- 每次重要分析至少给保守、基准、乐观三档。

需要用户：
- 提供真实数字，如收入、成本、现金流、概率、期限。
- 对假设允许“待核验”，不能伪造数据。

## 3. 现代制度跟踪

新增：`references/现代制度追踪协议.md`、`运行目录/学习记录/制度追踪表.md`。

本次落地：
- 建立政策清单：AI 监管、数据法、CFIUS、欧盟 AI Act、劳动法、税收等。
- 每周或每月核对一次，登记变化、来源和影响。

需要用户：
- 确认要重点跟踪的地区和领域。
- 提供官方网址或允许我搜索官方页面。

## 4. 执行追踪

新增：`运行目录/学习记录/执行追踪表.md`。

本次落地：
- 每个建议带行动、负责人、截止时间、关键指标、复查点、成功/失败信号。
- 复查后写回案例库或复盘文件。

需要用户：
- 提供真实执行结果。
- 允许我把结果登记到追踪表。

## 5. 危机陪伴与本地资源

新增：`references/危机转介清单.md`。

本次落地：
- 建立通用转介类别：心理、法律、医疗、报警、家庭暴力、自杀危机。
- 本地具体电话和机构需要用户补充，不凭记忆编造。

需要用户：
- 确认本地真实可用的热线、医院、法律援助和报警资源。

## 6. 跨文化视角

新增：`references/跨文化校准协议.md`。

本次落地：
- 国家、公司、家庭分析前先标出文化假设和区域差异。
- 历史案例跨文化使用时，说明适用条件和反例。

需要用户：
- 提供非西方制度、区域研究或国际案例资料。
