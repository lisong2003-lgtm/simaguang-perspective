# 行业模板与评审标准库（2026-08-17）

目的：按行业、输出类型和评审人关注点沉淀标准，避免用通用模板套所有项目。

## 建立方法

1. 确认行业：创业投资、企业服务、建筑工程、学术、媒体、出版、影视短剧、政府事务等。
2. 确认评审人：投资人、客户、评委、编辑、读者、平台审核、决策领导。
3. 反推评审标准：他们按什么打分、最怕什么、什么会直接淘汰。
4. 反推交付格式：篇幅、结构、证据、附件、合规要求。
5. 收集真实案例：公开案例、行业模板、用户提供的真实文件；不复制原文，只提炼结构。

## 种子标准

| 行业/场景 | 评审人关注 | 核心检查 |
|---|---|---|
| 创业投资 | 价值、团队、壁垒、回报、风险 | 路演 12 页、财务假设、融资用途、退出路径 |
| 招标应标 | 响应完整、资格合规、方案质量、价格 | 评分标准反推、废标检查、证明材料 |
| 学术论文 | 问题、方法、数据、贡献、局限 | 证据链、反方检验、参考文献规范 |
| 产品方案 | 用户、价值、可行性、可用性、商业性 | 用户场景、MVP、验证路径、复购指标 |
| 工程管理 | 安全、质量、进度、成本、资料 | 图纸规范、试验数据、施工日志、会议纪要 |
| 媒体非虚构 | 真实、可信、叙事、伦理、合规 | 信源、引语、事实核验、编辑终审 |
| 网文/出版 | 钩子、留存、人物、节奏、结局 | 开头、章节钩子、弃读点、编辑反馈 |
| AI 短剧/影视 | 观众留存、角色一致、节奏、合规 | 剧本、分镜、AI 标注、平台审核 |
| 政府与公共事务 | 依据、可行、稳定、风险、程序 | 政策依据、制度设计、执行路径、利益相关方 |

## 使用规则

- 模板是起点，不是终点；每个项目先填真实受众、目标、材料、约束。
- 行业模板必须来自真实公开资料或用户提供，不能凭书名猜测。
- 每个模板入库时记录来源、适用边界、已知失效条件。
- 真实反馈归档后，按反馈更新本库。
