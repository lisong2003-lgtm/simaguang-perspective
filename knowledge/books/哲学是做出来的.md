# 《哲学是做出来的》技能包（13 个）

## 1. 哲学即实践
- R：哲学是一种理性活动。它是最难、甚至不可能用一句简单明了的话概括主旨的一门学科。
- I：哲学不是背结论，而是通过阅读、写作、论证不断“做”出来的。
- A1：书中序言要求学生阅读柏拉图、笛卡尔、休谟、贝克莱，并写短文。
- A2：学习新领域、提升判断、写分析文时。
- E：读原文 → 重构论证 → 写辩护 → 接受批判。
- B：阅读量不等于能力，必须动手做。

## 2. 案例研究与思想实验
- R：思想实验能让我们屏蔽掉一些潜在干扰，专注于案例的关键所在。
- I：用受控的假想案例隔离变量，让原本纠缠的问题变清晰。
- A1：书中用古希腊“斯巴达荣耀号”与“忒拜少女号”讨论同一性与变化。
- A2：分析复杂问题、检验直觉、拆解争论时。
- E：简化情境 → 去掉干扰 → 明确关键变量 → 检验自己的直觉。
- B：思想实验不等于现实证据，结论仍要回到论证。

## 3. 第一法则：论证支撑观点
- R：无论什么观点，哪怕它再反常，都可以在哲学中进行合适的讨论。但持此观点的人有义务努力为其观点提供充分支持。
- I：结论不能只靠声明，必须给理由、建论证。
- A1：书中把“第一法则”当作哲学讨论最普遍的共识。
- A2：表达主张、说服别人、写报告时。
- E：写下结论；列出支持理由；检查理由是否真的支撑结论。
- B：不是所有断言都要立刻完整论证，但被追问时须能给出理由。

## 4. 论证形式检验
- R：一个由真前提出发的完好论证当然不可能得出一个错误结论。
- I：论证有效性取决于形式，不取决于结论是否顺耳。
- A1：书中用多个论证展示“真前提 + 无效形式 = 假结论”。
- A2：判断推理、反驳论证时。
- E：提取论证形式；构造反例；检查有效性。
- B：有效不等于前提真，可靠才要求形式与前提都成立。

## 5. 当心修饰语
- R：仅通过变换修饰语，就能使表达的隐含意味和逻辑关系产生奇特而意想不到的变化。
- I：“必然”“可能”“所有”“有些”的位置决定含义，表层语法会骗人。
- A1：书中用抵抗军故事与模态词作用范围说明隐藏的“如果”。
- A2：读合同、政策、承诺、声明时。
- E：标出修饰词；问它到底修饰什么；用“所有/有些/必然/可能”逐项重写。
- B：日常语言灵活，不能一律按形式逻辑读。

## 6. 质疑前提内容
- R：如果这个论证推出了让人不舒服或无法接受的结论，那么需要关注的必然就不是形式，而是其内容了。
- I：形式没问题时，就要逐条检查前提是否为真。
- A1：书中引用“某某的逻辑失误”并示范如何检查前提。
- A2：遇到逻辑正确但结论荒谬的论证时。
- E：先确认形式有效；逐条列出前提；对每条前提找反例或证据。
- B：不能因为不喜欢结论就否定前提，必须具体指出哪一条错。

## 7. 哲学写作辩护
- R：哲学文章是对某一论题进行有理可循的辩护。它不牵扯感觉与印象，既非报告亦非总结。
- I：写作要清晰阐述、精确表达、逻辑一致，而不是堆观点。
- A1：书中给出批判考察、裁定争论、解决问题三类文章框架。
- A2：写分析、做汇报、准备论证时。
- E：明确论题 → 摆立场 → 给论证 → 处理反例 → 收尾。
- B：文风重要，但不能用修辞代替逻辑。

## 8. 批判哲学家的五条路
- R：混义谬误、循环论证、无穷后退、对照不明、言之无物。
- I：批判一个人要找出论证中的具体缺陷，而不是只反对结论。
- A1：松鼠绕树（混义）、归纳问题（循环）、超限过程（后退）、贝克莱对话（对照不明）。
- A2：审阅方案、质疑结论、写反驳时。
- E：先检查关键词是否有歧义；再查是否循环；然后看是否无限后退、失去对照或空话。
- B：五条路是检查清单，不是攻击工具。

## 9. 定义、类比与思想实验
- R：判断一名哲学家所说是否为真，特别需要对哲学家所说的意义进行澄清。
- I：术语定义、类比和思想实验都是工具，能激发直觉，但不能单独证明真相。
- A1：书中讨论技术术语、日常词和思想实验的作用边界。
- A2：跨领域沟通、定义争议、创意方案时。
- E：先定义关键概念；用类比帮助理解；用思想实验检验直觉；最后回到论证。
- B：工具性假设不能被当成结论。

## 10. 裁定争论
- R：作者作为第三方来看待一场哲学争论，并力图说明争论各方的优劣势，进而做出裁定。
- I：不急着站队，先陈述各方立场和优劣，再给判决。
- A1：书中六部分结构：议题、立场1、评价1、立场2、评价2、判决。
- A2：调解冲突、评审方案、做最终决策时。
- E：呈现议题 → 列立场并评价 → 再列对方立场并评价 → 给出判决及理由。
- B：裁定不等于和稀泥，必须给理由。

## 11. 解决问题
- R：解决问题不仅需要说明与解释能力，更加需要原创能力和创造性眼光。
- I：先分析问题、设定标准，再探索方案、评估适用性、回应批评。
- A1：书中给出“表述问题→设定标准→探索备选→阐述方案→评估→回应批评”结构。
- A2：设计解决方案、开题、做咨询时。
- E：定义问题 → 定标准 → 探索备选 → 提方案 → 评估 → 回应反对。
- B：方案必须回到标准检验，不能只求新颖。

## 12. 刨根问底
- R：应该对问题刨根问底，对问题表层叙述中依据的特殊和一般预设予以揭露、明述和审查。
- I：表面问题与真正要害经常毫厘千里；先挖出隐藏假设。
- A1：书中强调“最重要的部分往往在于弄清问题到底是什么”。
- A2：接到模糊任务、讨论陷入僵局时。
- E：写下问题原文；列出隐含假设；逐条审查；重新表述真正问题。
- B：刨根问底要有边界，避免陷入无限追问。

## 13. 阅读哲学家的六种方式
- R：阅读哲学著作并不是为了读完，而是为了读深。
- I：阅读层次从结论、论证、辩证、批判、裁定到创造，逐层加深。
- A1：为结论读、为论证读、在辩证情境中读、批判地读、带裁定眼光读、创造性地读。
- A2：学习经典、研究方案、提升思考深度时。
- E：先抓结论 → 重构论证 → 放入历史对话 → 主动质疑 → 裁定优劣 → 形成自己的问题。
- B：深入不等于只读一本书，要进入对话体系。
