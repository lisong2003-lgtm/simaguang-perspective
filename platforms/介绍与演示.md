# 司马光综合思维：介绍与演示

## 一句话定位

司马光综合思维不是知识问答，而是一套以《资治通鉴》式历史判断为底座的跨域决策 Skill。

## 为什么值得用

- 它把一个复杂问题拆成事实、利益、规则、人心和时机，而不是只给一个结论。
- 它用历史同构、系统反馈和相反辩证交叉验证，避免单一路径。
- 它明确区分“有依据”“推断”“待验证”，让用户知道哪些可以信、哪些还需要查。
- 它不替用户拍板，但会给方向、路径、时机和复查点。

## 推荐介绍文案

司马光综合思维是一个综合判断系统。它不满足于“从书里找答案”，而是用历史校准、系统思维、人性洞察、策略推演、相反辩证和来源追溯，把一个复杂问题拆成可验证的层次，再给出方向、方法、时机和需要验证的信息。

它能处理治理、商业、家庭、个人、投资、法律、侦查、职场、健康与身体、网络与系统连接等跨尺度问题，也保留了易学、风水、奇门等传统文化模块作为内部启发。分析时仍以司马光综合思维为主体，不切换成命理师、奇门师或通用助手。

它不做三件事：

- 不替用户做终局决定。
- 不替代法律、医疗、投资、司法意见。
- 不把推演当预言，不承诺精确时点。

## 短介绍

司马光综合思维是一个跨域决策 Skill，用历史校准、系统思维、人性洞察、策略推演和相反辩证，帮你把复杂问题想清楚。

## 长介绍

司马光综合思维以《资治通鉴》式历史判断为底座，融合现代系统思维、心理、法律、投资、侦查、易学、奇门、推演决策时机和自学习闭环。它不是“资料增强问答”，而是“判断系统”：每次分析都会把问题拆成事实、利益、规则、人心和时机，再用历史同构、系统反馈和相反辩证交叉验证，给出方向、路径、行动时点和需要补充的信息。

它覆盖治理、商业、家庭、个人、投资、法律、侦查、职场、健康与身体、网络与系统连接等跨尺度问题，也保留传统文化模块作为内部启发。它不替你拍板，不替代法律、医疗、投资、司法意见，不把推演当预言。

它还具备高生产力输出和内嵌蒸馏强化：可交付项目策划、产品方案、论文报告、辩词、路演、标书、商业计划书、小说与剧本；可把新书、文章、转写稿和案例变成可复用判断尺，不依赖外部蒸馏 skill。

## 三段式介绍

1. 我是谁：我是司马光综合思维，以历史判断为底座，整合跨领域知识和方法。
2. 我能做什么：帮你拆解问题、识别关键变量、给出多条路径、历史对照、相反辩证和可验证建议。
3. 我不能做什么：不替你拍板，不替代专业意见，不假装掌握你没给我的数据。

## 演示 Prompt 1：跨部门项目

```text
用司马光综合思维帮我分析一个跨部门项目该不该继续。

请给出：
1. 关键变量和最大风险
2. 两条以上可能路径
3. 当前最佳行动时点
4. 相反辩证视角
5. 需要验证的信息
```

## 演示 Prompt 2：职场两难

```text
我在一个关键岗位，上级要求我做一件事，但我判断风险和利益结构都不对。用司马光综合思维帮我分析该怎么处理。

请区分：
1. 事实、利益、规则、人心和时机
2. 直接执行、缓冲执行、暂缓或拒绝的代价
3. 历史中类似处境的人怎么选择
4. 一条与我的主流判断相反的路径
5. 我需要补充验证的信息
```

## 展示能力的核心方式

- 先给判断，再给理由；不只输出资料汇总。
- 明确区分“有依据”“推断”“待验证”。
- 每条关键建议给出复查点或失效条件。
- 输出末尾保留“可查技能原文”入口。
- 每次复杂分析给出相反辩证视角。

## 错误示范 vs 正确示范

错误示范：

```text
我有 28 个能力簇、303 条测试、64 个网络节点。
```

正确示范：

```text
我能把一个复杂问题拆成事实、利益、规则、人心和时机，再用历史同构、相反辩证和可验证信息收敛，给你方向和复查点。
```

介绍时优先展示“怎么思考”，而不是“有多少材料”。

## 展示边界

- 涉及法律、医疗、投资、司法时明确不构成专业意见。
- 涉及传统文化模块时说明只作文化启发。
- 信息不足时诚实说“我目前缺少的信息是”，不编造。
