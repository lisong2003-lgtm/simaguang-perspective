# 司马光综合思维（公开版）

一个以《资治通鉴》式历史校准为基础的综合判断系统，融合现代系统思维、心理、法律、投资、侦查、易学、奇门、推演决策时机和自学习闭环。

## 特点

- 28 个能力簇
- 303 条测试
- 来源可追溯
- 自学习闭环
- 模块按需增强，日常不强制展示
- 高生产力输出：项目策划、产品方案、论文报告、辩词、路演、商业计划书、小说与剧本
- 内嵌蒸馏强化：不依赖外部蒸馏 skill，强化“如何把书变成可执行判断尺”
- 影视摄影与 AI 短剧：分镜、MiniMax H3、Seedance 2.5 提示词和 AI 短剧流程
- 高质量交付：输出自检、事实核验、专业边界复核、真实反馈闭环
- AIGC 美学、镜头语法、电影构图、剪辑语法

已并入新增技能：中医入门、深度工作、网络是怎样连接的、战争艺术史、刻板印象、二十四史。
公开版知识扩展包含 215 个脱敏逐书知识文件，覆盖非虚构写作、写作工艺、影视摄影、AIGC 提示词、战争论、东周列国志等最新并入内容。

完整产品说明见 `产品说明.md`。

## 安装

本目录是一个标准 Agent Skills 目录，核心文件为 `SKILL.md`。

常见安装方式：

- Codex / 通用 Skill 平台：把 `simaguang-perspective-public` 文件夹放入对应产品的 `skills` 目录。
- WorkBuddy：在设置页导入本压缩包，或把文件夹放入 `.codebuddy/skills/`。
- 其他平台：按平台对 `SKILL.md` 的导入要求执行。

## 快速开始

```text
用司马光综合思维帮我分析一个跨部门项目该不该继续。

请给出：
1. 关键变量和最大风险
2. 两条以上可能路径
3. 当前最佳行动时点
4. 相反辩证视角
5. 需要验证的信息
```

它的核心不是资料多，而是能把复杂问题拆成事实、利益、规则、人心和时机，再用历史同构、系统反馈和相反辩证交叉验证，给出方向、路径和复查点。

## 能力边界

- 不构成法律、医疗、投资、司法意见。
- 易学、风水、奇门只作文化启发。
- 不随包发布原始书籍文本。
- 不发布私人案例和本地路径。
- 识图、摄像头、OCR 需要外部视觉能力，本包不内置。
- 默认轻量包不包含逐书知识文件；知识扩展包含脱敏后的逐书知识文件。
- 实际调用依赖宿主按需读取 references 或 knowledge/books。

安装后按 `knowledge/summaries/<书>.md` 先读摘要，需要深度分析时再读 `knowledge/books/<书>.md`。
