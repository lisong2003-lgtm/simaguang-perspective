# 各平台发布步骤

## WorkBuddy

1. 使用通用轻量包：`simaguang-perspective-public-0.3.7.zip`
2. WorkBuddy 设置页导入 zip，或解压到 `.codebuddy/skills/`。
3. 需要深度能力时，把 `simaguang-perspective-public-0.3.7-knowledge.zip` 解压并合并 `knowledge/books/`。
4. 新开对话测试：

```text
用司马光综合思维帮我分析一个跨部门项目该不该继续。
```

## Codex 本地插件

1. 安装轻量插件：`simaguang-perspective-0.3.7-codex-plugin.zip`
2. 需要完整知识文件时，合并 `simaguang-perspective-0.3.7-codex-knowledge.zip`。
3. 新开对话测试，确认能读取 `knowledge/summaries/` 和 `knowledge/books/`。

## Codex 插件市场

1. 使用 `simaguang-perspective-0.3.7-codex-marketplace.zip`。
2. 解压后把 `simaguang-perspective-marketplace` 上传到公开仓库。
3. 确认 `marketplace.json` 路径为 `./plugins/simaguang-perspective`。
4. 用户安装：

```bash
codex plugin marketplace add <你的仓库地址>
codex plugin add simaguang-perspective@<市场名>
```

5. 知识扩展包可作为附加包单独提供。

## OpenAI Skills / Claude Skills / 通用 Skill 平台

1. 使用通用轻量包：`simaguang-perspective-public-0.3.7.zip`
2. 按平台要求导入 `SKILL.md` 目录。
3. 需要深度能力时，合并通用知识扩展包。
4. 如平台支持按需读取，保留三层调用；如不支持，至少使用摘要层和 references。

## 提交审核

每个平台提交时附上：

- 产品说明
- 隐私声明和能力边界
- 演示 Prompt
- 测试结果
- SHA256 校验文件
