# 司马光综合思维 发布流程

## 版本基线

当前公开版版本：`0.3.7-public`

## 发布包矩阵

| 包 | 用途 | 内容 |
|---|---|---|
| `simaguang-perspective-public-0.3.7.zip` | 通用轻量包 | 主 SKILL + references + 215 条书籍摘要 + 测试 |
| `simaguang-perspective-public-0.3.7-knowledge.zip` | 通用知识扩展 | 215 个逐书知识文件 |
| `simaguang-perspective-0.3.7-codex-plugin.zip` | Codex 本地插件 | 轻量插件 |
| `simaguang-perspective-0.3.7-codex-knowledge.zip` | Codex 知识扩展 | 插件可用的逐书知识文件 |
| `simaguang-perspective-0.3.7-codex-marketplace.zip` | Codex 市场仓库 | marketplace.json + 插件目录 |

## 发布前检查

1. 同步私人版公开内容，移除私人路径、私人案例和未授权版权文本。
2. 更新 SKILL、references、测试和产品说明。
3. 运行：

```bash
python3 scripts/check_integration.py
python3 scripts/run_test_prompts.py --prompts test-prompts.json
python3 scripts/build_release.py
python3 scripts/build_knowledge_extension.py
```

4. 核对 `dist/SHA256SUMS.txt` 与 `dist/README.md` 一致。
5. 在目标平台新开对话，跑一次演示 Prompt。
6. 发布后更新 CHANGELOG 和平台提交材料。

## 发布后维护

- 每次技能更新后重新打包并更新 SHA256。
- 收集真实反馈，按高生产力反馈闭环协议归档。
- 每季度复盘书籍贡献率，更新版本说明和产品定位。
