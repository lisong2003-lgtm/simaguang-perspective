# 发布提交材料

## 提交文案

**名称：** 司马光综合思维
**作者：** lis

**一句话简介：** 以《资治通鉴》式历史校准为基础的综合判断系统，把复杂问题拆成可验证的层次，再给出方向、路径、时机和待验证信息。

**详细介绍：**

司马光综合思维不是普通知识问答，而是一套可执行的综合判断系统。它不满足于“从书里找答案”，而是用历史校准、系统思维、人性洞察、策略推演、相反辩证和来源追溯，把一个复杂问题拆成事实、利益、规则、人心和时机等层次，再给出方向、路径、时机和需要验证的信息。

它覆盖治理、商业、家庭、个人、投资、法律、侦查、职场、健康与身体、网络与系统连接等跨尺度问题，并保留易学、风水、奇门等传统文化模块作为内部启发。分析时仍以司马光综合思维为主体，不切换成命理师、奇门师或通用助手。

它同时具备高生产力输出和内嵌蒸馏强化：能把项目策划、产品方案、论文报告、辩词、路演、标书、商业计划书、小说与剧本等成果直接落到可交付结构；也能把新书、文章、转写稿和案例变成可复用判断尺。

它还支持影视摄影、AI 短剧和高质量交付机制：可从故事、剧本、分镜推进到 MiniMax H3、Seedance 2.5 提示词；交付前做输出自检、事实与数据核验、专业边界复核，交付后按真实反馈闭环更新。

**适用人群：** 需要综合判断、决策推演、历史对照、反向辩证和来源追溯的用户。

**快速上手 Prompt：**

```text
用司马光综合思维帮我分析一个跨部门项目该不该继续。
```

司马光综合思维是一个跨域决策 Skill，用历史校准、系统思维、人性洞察、策略推演和相反辩证，帮你把复杂问题想清楚、做出可验证的判断。

中版（约 150 字）：

司马光综合思维不是知识问答，而是综合判断系统。它把复杂问题拆成事实、利益、规则、人心和时机，再用历史同构、系统反馈和相反辩证交叉验证，给出方向、路径、行动时点和需要补充的信息。适合治理、商业、职场、家庭、投资、法律、侦查和日常决策。

长版（约 300 字）：

司马光综合思维以《资治通鉴》式历史判断为底座，融合现代系统思维、心理、法律、投资、侦查、易学、奇门、推演决策时机和自学习闭环。它不以“资料多”为能力，而以“判断是否可验证”为能力。每次分析会区分有依据、推断和待验证，保留相反辩证视角，并给出复查点。

它覆盖治理、商业、家庭、个人、投资、法律、侦查、职场、健康与身体、网络与系统连接等场景，也保留传统文化模块作为内部启发。它不替你拍板，不替代法律、医疗、投资、司法意见，不把推演当预言。

```text
请给出：
1. 关键变量和最大风险

4. 相反辩证视角
5. 需要验证的信息
```

```text
我遇到一个职场两难：上级要求我执行，但我判断风险和利益结构都不对。用司马光综合思维帮我分析。
```

## 用户能感受到的差异

- 先给判断，再给理由，而不是先堆资料。
- 明确区分“有依据”“推断”“待验证”。
- 给出至少两条路径和相反辩证视角。
- 每条关键建议带有复查点或失效条件。
- 输出末尾保留“可查技能原文”入口。

## 隐私声明

- 不发布原始书籍文本。
- 不发布私人案例、个人路径和聊天记录。
- 不包含第三方配置管理工具配置、施工日志、会议纪要或名人私有分析。

- 依赖模型服务商，不独立运行。

- 易学、风水、奇门只作文化启发，不用于现实重大决策。
- 紧急情况建议寻求专业帮助。
